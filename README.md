# Trello-API-Testing-Postman

## Project Overview

An API testing project focused on validating Trello REST APIs using
Postman.

## Objectives

- Validate API functionality
- Verify HTTP status codes and response schemas
- Perform positive and negative testing
- Validate CRUD operations
- Implement API request chaining
- Use dynamic variables
- Automate API assertions using Postman scripts
